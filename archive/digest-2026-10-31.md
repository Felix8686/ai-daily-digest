## ⚡ 行业异动：新模型 · 降价 · 羊毛福利 · 接口预警

**[Liquid AI 发布 LFM3：1.7B 级骨架里装下六个多模态模型，专为端侧 Agent 设计](https://alphasignal.ai/news/liquid-ai-s-lfm3-packs-six-multimodal-models-into-a-1-7b-open-weight-family)** (来源: AlphaSignal)

Liquid AI 把六个专用模型塞进一个共享的 2B 骨干里，用三混合架构替掉标准 Transformer 块，目标很明确：让多模态 Agent 在本地设备上跑，而不是什么都往云端送。

对普通人的实际意义：小参数、多模态、面向端侧，意味着以后本地跑图文/语音小助手又多了一个开源选项。别急着吹“颠覆”，先等权重和推理脚本放出来，拿自己的 Mac 或带独显的机器试跑一轮再下结论。

**[OpenAI 开始认 robots.txt 里的“AI 训练偏好”共享信号：有个人网站的人必须知道](https://openai.com/index/helping-websites-express-ai-training-preferences)** (来源: OpenAI News)

OpenAI 表示会遵守一个共享的 robots.txt 信号，让网站运营者能统一表达“允不允许 AI 拿我的内容做训练”。

说人话：如果你有个人博客、作品站、独立域名，这是一次规则层面的变化——以前你写一堆 Disallow 也未必有用，现在至少有了一个参与方承认的统一表达方式。但注意两点：一是**自愿参与**，不是所有 AI 厂商都认；二是**别以为默认保护**，你不主动配置，别人照样爬。做内容站的朋友，值得花十分钟检查一下自己的 robots.txt。

## 💻 本地平替与上手神器

**[Maya 2 Native：Apache-2.0 免费开源 TTS，12 种语言、20 种声音、支持零样本克隆](https://alphasignal.ai/news/maya-research-drops-maya-2-native-a-free-12-language-voice-ai)** (来源: AlphaSignal)

流式 TTS，覆盖 11 种印度语言加英语，20 个预置声音，零样本克隆，Apache-2.0 可商用可本地部署。

对公众号主最直接的价值：口播配音、短视频旁白、批量音频内容，不用再按字数买 API。自己机器上跑，隐私和成本都捏在手里。缺点是语言包偏印度语系，中文效果得自己实测，别盲信宣传。

**[Nocto：把 MacBook 那块碍眼的刘海变成真正有用的信息栏](https://www.producthunt.com/products/nocto)** (来源: Product Hunt)

MacBook 的刘海终于不只是“为了摄像头挖的坑”。Nocto 把这块区域变成常驻信息显示区，状态、提示直接怼在眼前。

省时间的地方很朴素：少切窗口、少低头看菜单栏。轻量小工具，装上就用，不折腾。适合天天对着 Mac 写稿、剪片、跑 Agent 的人。

**[GitHub spec-kit：给 AI 编程 Agent 套上“先写规范再动手”的官方流程模板](https://github.com/github/spec-kit)** (来源: GitHub Trending)

GitHub 官方出的工具包，核心是 SDD（规范驱动开发）：先让 Agent 按模板写清楚要做什么、验收标准是什么，再让它动手写代码，附带可复用流程和文档化产出。

痛点很真实：AI 编程助手最大的浪费不是不会写，是**没想清楚就乱写、写完你再返工**。spec-kit 就是给 Claude Code、Codex 这类工具立规矩的。对自建自动化、经常让 Agent 改脚本的人，能省下大量“改了又改”的时间。需要一点配置，不是点开即用，但值得。

## 🎯 创作者风控与爆款选题

**[把红白机 NES 模拟器“烤”进 Qwen3.5-4B 的权重里，还真能慢速跑超级马里奥](https://simonwillison.net/2026/Oct/30/nesformer/)** (来源: Simon Willison)

Drew Breunig 受 qwenputer 启发，把一个能工作的 NES 6502 CPU 模拟器直接烘焙进 Qwen3.5-4B 的模型权重里，现在你可以在模型内部慢速跑《超级马里奥》这类 ROM。作者还在 HN 评论区公开了用 Opus 5.5 构建这套东西的提示词。

这不是生产力工具，但它是极好的**反差型爆款素材**：大家天天聊 Agent 干活，突然有人把红白机塞进 4B 小模型里跑起来了。

【写作切入点建议】别写成技术论文，就写“AI 整活”：《我把一台红白机塞进了 4B 小模型，它真的跑起来了》——重点放在“普通人也能围观的荒诞感”和“提示词怎么把这事一步步逼出来”，顺带聊一句“模型权重里到底能装下多少奇怪的东西”。流量密码是猎奇 + 可复现。

## 🔍 暗改排雷与避坑打假

**[Cursor 市场的 Claude Code 扩展被投毒，最多 5000 名开发者机器被植入 SSH 后门](https://alphasignal.ai/news/cursor-s-claude-code-extension-was-hijacked-exposing-5-000-developers-to-ssh)** (来源: AlphaSignal)

一个被 Trojan 化的 Claude Code 扩展混进 Cursor 插件市场，在最多 5000 台开发机上植入 SSH 后门，之后才被下架。

这条不是看热闹，是实打实的避坑：

- **别乱装第三方市场里的“增强插件”**，尤其是要读写你本地文件、执行命令、碰 SSH 配置的。
- 已经装过来源不明扩展的，去查 `~/.ssh/authorized_keys` 有没有陌生公钥，检查 shell 启动脚本有没有被塞东西。
- 自建 Agent、天天让工具跑本地命令的人，风险比普通用户高一个量级——供应链攻击防不胜防，权限能收就收。

省钱是小事，机器被人留后门是大事。今天就去清一遍插件列表。
