## 💻 本地平替与上手神器

**[(60 块的小米蓝牙遥控器 2 Pro，被改成了 vibe coding 专用手柄)](https://sspai.com/post/114741)** (来源: 少数派)

- 核心思路很简单：把「让 Agent 继续跑」「批准这次改动」「切窗口」这类高频动作映射到遥控器按键上，人从键盘前解放出来。

- 具体映射方案看原文，作者是实测过的。

**[(AgentGrid.io：让人类和 AI Agent 共用一块工作区的网页工具)](https://www.producthunt.com/products/agentgrid-io)** (来源: Product Hunt AI)

- 官方介绍只有一句「Shared workspace for humans and agents」，**没给细节，需要自己点开看**——这点我如实说，不替它吹。

**[(Simon Willison 一句话让 Claude 造出一张四人对战地图：vibe coding 的真实上限样本)](https://simonwillison.net/2026/Oct/24/battledrones/)** (来源: Simon Willison)

- 想练手的话，这是最容易复现的一类项目：纯前端、无后端依赖、本地就能跑。

## 🎯 创作者风控与爆款选题

**[(NotebookLM 的「视频概览」系统提示词被完整拆解出来了)](https://baoyu.io/blog/2026-10-20/notebooklm-video-overview-system-prompt)** (来源: 宝玉的分享)

- 宝玉把整套工作流拆成三段：上下文收集 → 审核卡片 → 视频生成，连提示词原文都给了。这意味着**你可以照着复刻一个「长文转视频」的流水线**，而不是只能用官方那一个按钮。
- **【写作切入点建议】**：把你自己一篇 5000 字的公众号长文丢进去，逐帧对比「AI 讲的和我想讲的差在哪」——《我让 AI 把我的文章拍成视频，它删掉了我最想说的那段》。

**[(选题：和 AI Agent 共用一张桌子，到底是提效还是添乱)](https://www.producthunt.com/products/agentgrid-io)** (来源: Product Hunt AI)

- 这类「人机共享工作区」产品正在密集出现，但没人写真实体感。**你每天跑 Hermes 的日常，就是最好的样本。**
- **【写作切入点建议】**：记录一天里被 Agent 打断、需要人工介入、以及它自作主张的次数——用数字说话，别写感想。
