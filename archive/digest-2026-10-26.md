## ⚡ 行业异动：新模型 · 降价 · 羊毛 · 接口预警

**[Depono：多个大模型随便切换，只按上游成本加价 10%，聊天文件存进 Git](https://depono.xyz/)** (来源: Hacker News / Show HN)

一句话：把 API 计费模式从“套餐价”变成“进货价 + 10% 跑腿费”，还能把你和模型的全部对话按文件形式留在 Git 仓库里，版本可回溯、可 diff。

- **为什么值得看**：你如果经常在 Claude、GPT、Gemini 之间来回比价，最烦的就是订阅制“用不完作废、超了再买”。按成本计价 + 10%，至少定价逻辑是透明的。
- **对你的实际价值**：和 Hermes 这类自建 Agent 天然合拍——对话记录本来就该是纯文本、可进版本库的资产，不该只锁在某个网页的聊天框里。
- ⚠️ 冷静一下：这是 Show HN 上刚冒头的小项目（当前仅 1 分），**先小额试，不要把主力工作流迁过去**。

**[Arc 浏览器宣布下线：你的 Space、固定标签、自动化脚本要提前搬家](https://sspai.com/post/117460)** (来源: 少数派 · 派早报)

这是今天**唯一一条真正的 Breaking Change**，别当八卦看。

- **谁受影响**：把 Arc 当主力浏览器、在上面存了几十个 Space、装了一堆扩展做半自动化的你。浏览器一停，等于工作流的中枢神经被剪断。
- **今天该做的三件事**：① 导出书签与所有 Space；② 把浏览器里跑着的自动化脚本、快捷键映射逐条记下来；③ 确认密码库是否已同步到独立管理器（别只存在浏览器里）。
- 具体时间表与迁移方案看原文，别拖。

## 💻 本地平替与上手神器

**[God：给一堆 AI Agent 装个“实时监控大屏”，开源免费，EMNLP 2026 现场演示项目](https://github.com/XiaoLuoLYG/GOD)** (来源: Hacker News / Show HN · GitHub)

**解决什么问题**：你跑多 Agent 编排时最抓狂的不是它做错，而是**你不知道它现在在干嘛**——卡在哪个环节、谁在等谁、哪个子任务死循环烧钱。

- 这个项目做的是“Agent 社会的实时控制室”，把多个 Agent 的运行状态摊开给你看。
- **对 Hermes 用户几乎是刚需**：多 Agent 工作流一旦超过三个角色，靠翻日志调试的效率低得可怕。
- ⚠️ 说清楚：EMNLP demo 级项目，代码量和稳定性别抱生产级期待。**拿来观察和调试可以，别挂到关键链路上**。

**[AgentGrid.io：人类和 Agent 共用的协作工作区](https://www.producthunt.com/products/agentgrid-io)** (来源: Product Hunt)

概念方向对——不再把 AI 当聊天框，而是当成一个“坐在你旁边的同事”，共享同一块工作区。

- **实话实说**：Product Hunt 上目前只有一句介绍，功能细节、定价、是否支持本地部署全都不明。**今天先收藏观望，别急着注册绑卡**。
- 但这类产品值得盯：它代表的方向（人机同屏协作，而不是人机对话）大概率是明年个人工作流的主形态。

**[60 元小米蓝牙遥控器 2 Pro，改造成 vibe coding 专属快捷键](https://sspai.com/post/114741)** (来源: 少数派 Matrix)

今天最“接地气”的一条，也是最容易被低估的一条。

- **核心思路**：把遥控器的实体按键映射成快捷键，绑到「语音输入」「跑脚本」「切窗口」「触发 Agent」上。手不用离开椅子，思路不断线。
- **省下的时间**：单次只省几秒，但 vibe coding 的敌人从来不是打字慢，而是**每次伸手够键盘都在打断心流**。物理按键的价值在于它不占屏幕、不用看、盲操作。
- 60 块钱的试错成本，比买任何“AI 效率课”都值。

## 🎯 创作者风控与爆款选题

**[Freehire：开源扒了 300 万+ 技术岗，全部来自公司官网直招，还带 AI 改简历](https://freehire.me/)** (来源: Hacker News / Show HN)

- **它做了什么**：直接爬各家公司的招聘官网，聚合成可筛选的岗位库，附带求职进度跟踪和按你技能偏好定制的简历改写。数据源绕开了招聘平台这个中间商。
- **【写作切入点建议】**：别写成工具测评，写成**实测体**——《我用开源工具扒了 300 万个官网直招岗位，投了 50 份简历，说说哪些环节真的省事了、哪些纯属白费劲》。读者要的不是功能列表，是“官网直招到底比招聘 App 强在哪、AI 改简历会不会一眼假”。
- 顺带一句：开源 + 数据来自公开官网，这个组合本身就是很好的“普通人信息差”素材。

## 🔍 暗改排雷与避坑打假

**[Spotify 家庭组要定期扫码验证：拼车党、代充党的低价会员要凉](https://sspai.com/post/117460)** (来源: 少数派 · 派早报)

- **发生了什么**：家庭组成员被要求定期扫码验证真实位置，共享会员的“地理漏洞”被堵上。
- **谁该紧张**：在二手平台拼车、找代充买“年付 30 块家庭会员”的人。**这类账号一旦验证失败，钱基本追不回来**，代充方早就跑路了。
- **排雷建议**：还在用非官方渠道的家庭组，趁现在把重要歌单导出备份，别等到某天早上打开发现账号被踢、订阅作废。省下的几十块，赔进去的是几年歌单和一次扯皮。
- **顺带一提**：同一份早报里还有“谷歌建虚拟电厂、付费激励用户省电留给 AI”——别当成薅羊毛机会。那点补贴换的是你家用电行为的让渡权，本质是给数据中心腾电，普通用户收益极低，不值得为它折腾智能家居。
