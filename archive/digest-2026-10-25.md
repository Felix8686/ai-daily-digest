## ⚡ 行业异动：新模型 · 降价 · 羊毛福利 · 接口预警

**[Kimi K3.1 Pro 上线 API：权重 11 月 4 日开源，但“高速版”价格翻倍要当心](https://simonwillison.net/2026/Oct/23/kimi-k31-pro/)** (来源: Simon Willison)

月之暗面今天把 K3.1 Pro 推上了 Kimi API。三件事你必须知道：

- **定价**：输入 $2/百万 token，输出 $10/百万 token。这个价位对标的是中高端闭源模型，不是白菜价。
- **“Highspeed”版本是个坑**：速度快 2-3 倍，但价格直接翻倍——**唯独输入 token 缓存命中部分同价**。如果你跑的是长上下文、重复 prompt 的 Agent 工作流，缓存命中率高的话高速版还算划算；如果是短对话高频调用，别碰。
- **开源承诺**：官方说 11 月 4 日前放出完整权重。想本地部署的，先别急着充钱，等两周看权重质量再决定。

**给你的行动建议**：如果你 Hermes 里有跑 Kimi 的自动化链路，今天先做一次成本测算——把最近一周的 token 消耗拉出来，按新价格重算，看看账单会涨多少。别等月底账单出来才肉疼。


## 💻 本地平替与上手神器

**[Hurston-1：Apache-2.0 开源 TTS，专攻美国南方口音和非裔英语](https://huggingface.co/destined/hurston-1)** (来源: Hugging Face)

一个亚特兰大团队开源的窄带 TTS 模型，Apache-2.0 协议，商用无限制。亮点不在“又一个 TTS”，而在于它专门优化了主流模型普遍拉胯的口音场景——美国南方口音和区域性非裔英语。

**能帮你省什么**：如果你做播客、视频配音，或者需要给英文内容配多口音旁白，这东西直接省掉外包配音的钱。Hugging Face 上直接试听，本地跑推理对消费级显卡友好（窄带模型，显存需求低）。

**[Quick Study：上传照片，几秒内用画布“画”出油画版](https://simonwillison.net/2026/Oct/23/quick-study-painter/)** (来源: Simon Willison)

Simon Willison 用 Claude Opus 5.5 生成的一个 artifact 工具：打开一张照片，几秒内用 canvas 元素模拟画笔，把照片“重绘”成绘画风格。底层用的是 Sobel 边缘检测，除 Google Fonts 外零外部依赖。

**能帮你省什么**：做公众号封面图、文章配图时，想要“手绘感”又不想开 Photoshop 的，这个点开就能用。而且它是单文件 artifact，你可以直接丢给 Claude 让它改成你想要的风格（水彩、素描、版画都行）。

**[Basedash 定时 CSV 导出：问一次，每周自动把数据推到 Slack/邮箱](https://www.producthunt.com/products/basedash)** (来源: Product Hunt)

一句话描述需求，它每周定时给你生成一份新鲜 CSV，直接推到 Slack 或邮箱。不用写 cron、不用配 webhook、不用维护脚本。

**能帮你省什么**：如果你每周要手动从后台导数据做周报，这个能直接砍掉那 15-20 分钟的重复劳动。对做自媒体数据复盘（阅读量、涨粉、转化）的号主尤其实用。

## 🔍 暗改排雷与避坑打假

**[Kimi “Highspeed” 版本的定价结构：速度翻倍，价格也翻倍，只有缓存命中不涨](https://simonwillison.net/2026/Oct/23/kimi-k31-pro/)** (来源: Simon Willison)

这条单独拎出来排雷，因为它的定价设计很容易让人误判。表面看“高速版”是个升级选项，实际上：

- 输入 $2 → 高速版翻倍，**除非你的请求大量命中输入缓存**
- 输出 $10 → 高速版同样翻倍，**输出 token 没有缓存一说，实打实翻倍**

**谁该用高速版**：长文档分析、RAG 检索这类输入巨大且重复率高的场景，缓存命中能把输入成本压回来。
**谁别碰**：短对话、高频 Agent 调用、内容生成类任务——输出占大头，翻倍就是翻倍，速度提升换不来成本。

**一句话**：别被“Highspeed”这个名字骗了，先算你的输入/输出 token 比例再决定。
