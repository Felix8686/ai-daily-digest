## ⚡ 行业异动：新模型 · 降价 · 羊毛福利 · 接口预警

**[Hurston-1：开源窄带 TTS，专攻美国南方口音与黑人英语](https://huggingface.co/destined/hurston-1)** (来源: Hacker News / HuggingFace)

Apache-2.0 协议，可商用可本地跑。主流 TTS（ElevenLabs、Azure）对南方口音、非裔英语的处理一直是短板，这个模型专门补这个洞。**对你的价值**：如果你做英文播客、给 Hermes 加语音播报、或想给公众号做英文配音，这是目前少见的"口音真实感"开源选项。窄带意味着模型小、CPU 也能推，Mac 本地跑无压力。

> ⚠️ 接口预警：今日素材中**无**主流 API 降价、免费额度调整或停服公告。OpenAI 那篇是存储基建（1 亿用户级），跟你无关，已过滤。

## 💻 本地平替与上手神器

**[1Password for Agents：让 AI Agent 登录但不让它看见你的密码](https://www.producthunt.com/products/1password)** (来源: Product Hunt)

这是今天**最该点开**的一条。你跑 Hermes 自动化，绕不开"Agent 要登录某个网站"的坎——现在要么把密码明文塞进配置，要么手动代劳。这个产品让 Agent 完成登录动作，但密码对 Agent 不可见。**省下的时间**：不用再为每个自动化脚本单独管理凭据，也不用担心 prompt 注入把密码套走。对自建 Agent 的人是刚需级补丁。

**[Mood Writer：带番茄钟 + 白板 + 自然音效的极简写作器](https://www.moodwriter.app/)** (来源: Hacker News)

网页即开即用，零安装。写作时播自然音、内置番茄钟排工作/休息、旁边一块白板放参考素材和灵感。**省下的时间**：省掉"写作器 + 番茄钟 App + 白噪音网站 + 便签"四个窗口来回切。适合你写公众号初稿时用，专注度直接拉满。

**[ADRs for AI：把"人机协作的决策过程"用 Git 版本化](https://adrs.systems)** (来源: Hacker News)

架构决策记录（ADR）的 AI 版——记录你和 AI 一起做某个决定的来龙去脉，存进 Git。**对你的价值**：你 Obsidian 知识库 + Hermes 自动化，最怕的就是"三个月后忘了当初为什么这么设计 prompt/工作流"。这个思路可以直接搬进你的笔记体系，不一定用它的产品，但**方法论值得抄**。
