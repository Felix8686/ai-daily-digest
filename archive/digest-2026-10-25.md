## ⚡ 行业异动：新模型 · 降价 · 羊毛 · 接口预警

**[一个给人和 AI 共用的开源浏览器工作台](https://github.com/zephium-browser/Zephium)** (来源: Show HN / 独立开发者)
- 用 Rust 写的，基于系统的 WebView（fork 了 Wry），**不是 Chromium 套壳**，安装包只有 40MB。内置原生广告拦截（fork 自 adblock-rust），支持主流 Chrome 扩展，还带一个自研的 agent 浏览引擎。
- 最关键的卖点是 **Work mode**：人和 AI agent 在同一个浏览环境里查资料、做研究、共享上下文。这正好是 Hermes 这类自建 agent 最缺的一环——现在你让它上网，要么开 Playwright（重、慢、容易被风控识别），要么手动复制粘贴。
- **提醒**：Show HN 上只有 1 分，纯早期项目。值得放进收藏夹关注，**别今天就把它放进你的生产流程**。真正该记下的是方向：浏览器正在从“人用的工具”变成“agent 的入口”，这一层今年一定会重新洗牌。

**[给 AI 编程助手装个“写安全规则”的技能包](https://github.com/ajaynyayapathi/yara-l-skill)** (来源: Show HN / 独立开发者)
- 一个 Agent Skill，教 AI 编程 agent 去写、审、调、转换 YARA-L 2.0 检测规则（Google SecOps，原 Chronicle）。
- 这个项目本身很小众，但**它的做法值得你照搬**：把你的领域知识（公众号排版规范、Obsidian 笔记模板、选题库字段规则）打包成一个 skill 文件交给 Hermes，agent 就从“会聊天的”变成“懂你这套规矩的”。
- 一个趋势判断：Agent Skill 正在从“会写代码”扩展到“会写专业规则”。这是普通人能吃到红利的一层——**你有别人没有的领域知识，就能封装成别人没有的 skill**。

## 💻 本地平替与上手神器

**[140 多个新闻源喂出来的 AI 热度地图](https://ai.jagular.io)** (来源: Show HN / 独立开发者)
- 打开就是一张热力图，数据来自 140+ 个新闻源的实时聚合。**它实际省下的，是你每天早上刷十几个 RSS 和公众号的那 20 分钟。**
- 用法建议：别当新闻读，当**选题雷达**读。只看“突然变红但还没被中文号写烂”的格子，那就是你下一篇文章的窗口期。
- 需要注意：源的质量和权重它没说清，前两周先拿它跟你现有的信息源交叉验证，别直接信。

**[让工作自动找上你的职位匹配工具](https://four-leaf.ai/jobs)** (来源: Show HN / 独立开发者)
- 逻辑是反过来：不是你去搜岗位，是它按你的画像持续匹配然后推给你。零门槛，填完就能看结果。
- **但先说清风险**：这类“自动匹配/自动投递”产品最容易出问题的地方是——它拿你的简历去投了你根本不知道的岗位，等你发现时已经进了某家公司的库。建议**只填公开信息，先别给自动投递授权**，跑一周看它推的东西靠不靠谱再决定。

## 🎯 创作者风控与爆款选题

**[NotebookLM 生成视频的完整提示词工作流，被人扒出来了](https://baoyu.io/blog/2026-10-20/notebooklm-video-overview-system-prompt)** (来源: 宝玉的分享)
- 宝玉把 NotebookLM 的 Video Overview 那套系统提示词和完整创作流程拆开了：上下文怎么收集、review cards 怎么过一遍、最后怎么生成视频。
- **这是今天最有实操价值的一条**。你可以直接照着这套流程，在本地用 Claude 或 GPT 复刻一个“输入一堆资料 → 输出讲解视频脚本”的流水线，不用等 Google 给你开权限。
- 【写作切入点建议】别写成“NotebookLM 有多神”，写成**《我把 NotebookLM 做视频的底裤扒了：它其实是这么写脚本的》**——把提示词原文贴出来，逐段讲它为什么这么设计，再给出你在本地复刻的版本。这种“拆开看内部”的稿子，比任何测评都更容易被转发。

**[一句话让 Claude 给我做了张四人联机对战地图](https://simonwillison.net/2026/Oct/24/battledrones/)** (来源: Simon Willison)
- Simon 给他的小游戏 Battledrones 加了四人在线模式，新地图是他**用一段 prompt 让 Claude 生成的**：四向旋转对称、最多四个 AI 玩家、兼容 WebSocket 非音频多人模式，空位自动补 AI。
- 【写作切入点建议】别写“AI 取代程序员”这种老套话。写**《一个人 + 一个 agent，能养多大的玩具项目》**——把原始 prompt、Claude 第一次写错的地方、你改了几轮全贴出来。读者要看的不是结果多酷，是“我一个普通人照着做能不能行”。
- 顺带一个风控提醒：这类“AI 生成讲解视频、AI 生成游戏素材”的流水线一旦跑起来，你就进入了**平台 AI 内容标识的高危区**。公众号和小红书目前的态度很明确：不禁止你用，但你得标。批量产出前先把标识规则摸清，别等被限流了才回头补。

## 🔍 暗改排雷与避坑打假

**[百度世界 2026 前瞻：10+ 重磅分论坛，全面解码智能组织进化路径](https://www.qbitai.com/2026/10/504901.html)** (来源: 量子位)
今天这条，连带另外两条，一起划走：
- **百度世界大会前瞻**：通篇是“分论坛数量”和“智能组织进化路径”，写给企业客户和投资人看的。你的个人工作流一个字都用不上。
- **Google 那份东南亚数字经济 3680 亿美元报告**：宏观总量数字，除了当标题党素材没有任何用途。别拿它写稿，读者一眼就能看出来你在凑字数。
- **Product Hunt 上那类“AI + 一个动词”的壳产品**（比如今天的 LinkIntel，摘要就一句话“把帖子洞察直接送进你的 AI 讨论”，连产品是什么都没说清）：这类产品九成是套了个模型 API 的网页，活不过三个月。**判断标准很简单：它能不能用一句话说清“帮我省了哪一步”？说不清，就是智商税。**
- 补一条：少数派那篇硅谷计算机历史博物馆的游记，读着舒服，但属于情怀消费，不产出任何可落地的东西。周末当消遣看，别当素材。
